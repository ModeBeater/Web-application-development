# Raise Hand — REST API reference

Base URL: `http://localhost:8000` (the `WEB_PORT` from `.env`).
Interactive version of this document: **http://localhost:8000/docs/** (Swagger UI, rendered from
[`backend/openapi.yaml`](../backend/openapi.yaml), which is also served at `/openapi.yaml`).
Ready-made requests: [`postman/RaiseHand.postman_collection.json`](../postman/RaiseHand.postman_collection.json).

## Conventions

| Topic | Rule |
|---|---|
| Format | Request and response bodies are JSON. Send `Content-Type: application/json`. |
| Lecture key | `{key}` is the numeric **id** (`12`) **or** the 6-character **join code** (`KBTU26`, case-insensitive). |
| Question id | `{id}` is the numeric id only. |
| Success codes | `200 OK` read/update · `201 Created` create · `204 No Content` delete (empty body) |
| Error codes | `400` bad input · `404` unknown id/code · `405` wrong HTTP method · `409` lecture closed · `503` database down |
| Error body | always `{"error": "<human readable message>"}` |
| Text fields | trimmed, inner whitespace collapsed; limits: title 120, text 500, author 40 characters |
| Timestamps | ISO 8601 with offset in the project time zone (`Asia/Almaty`), e.g. `2026-10-28T23:34:13+05:00` |
| Auth | none yet (next assignment) — every endpoint is open; writes are CSRF-exempt |
| Voter | upvotes are per *voter*: the `voter` cookie (set automatically) or an explicit `"voter"` value in the body |

## Endpoint overview

| Method | Path | Purpose | Success |
|---|---|---|---|
| GET | `/api/` | API root: version and links | 200 |
| GET | `/health/` | App + database health (Docker `HEALTHCHECK`) | 200 / 503 |
| **Lectures** | | | |
| GET | `/api/lectures/` | List lectures (`?q=`, `?is_open=`) | 200 |
| POST | `/api/lectures/` | Create a lecture | 201 |
| GET | `/api/lectures/{key}/` | Get one lecture **with its questions** | 200 |
| PUT | `/api/lectures/{key}/` | Replace (title required, is_open optional) | 200 |
| PATCH | `/api/lectures/{key}/` | Partial update (any of title, is_open) | 200 |
| DELETE | `/api/lectures/{key}/` | Delete lecture + its questions and upvotes | 204 |
| POST | `/api/lectures/{key}/toggle/` | Open ⇄ close the lecture | 200 |
| **Questions** | | | |
| GET | `/api/lectures/{key}/questions/` | Questions of one lecture, screen order | 200 |
| POST | `/api/lectures/{key}/questions/` | Ask (create) a question in the lecture | 201 / 409 |
| GET | `/api/questions/` | All questions (`?lecture=`, `?answered=`, `?q=`, `?limit=`, `?offset=`) | 200 |
| GET | `/api/questions/{id}/` | Get one question | 200 |
| PUT | `/api/questions/{id}/` | Replace (text required; author, is_answered optional) | 200 |
| PATCH | `/api/questions/{id}/` | Partial update (any of text, author, is_answered) | 200 |
| DELETE | `/api/questions/{id}/` | Delete question + its upvotes | 204 |
| POST | `/api/questions/{id}/upvote/` | Toggle the caller's upvote | 200 |
| POST | `/api/questions/{id}/answered/` | Toggle the answered flag | 200 |

## Objects

### Lecture

```json
{
  "id": 1,
  "title": "Flutter 1 · Lecture 00 · Course introduction",
  "code": "KBTU26",
  "is_open": true,
  "question_count": 3,
  "created_at": "2026-10-28T23:34:13+05:00",
  "join_url": "http://localhost:8000/l/KBTU26/",
  "screen_url": "http://localhost:8000/l/KBTU26/screen/"
}
```

`code` is generated by the server and never changes. `join_url` is the address encoded in the QR code
(`PUBLIC_URL` from `.env`, else the running Cloudflare tunnel, else the address of the request).
`GET /api/lectures/{key}/` additionally contains `"questions": [...]`.

### Question

```json
{
  "id": 1,
  "lecture_id": 1,
  "lecture_code": "KBTU26",
  "text": "Do I need to know Dart well before starting with Flutter?",
  "author": "Aigerim",
  "votes": 2,
  "voted": false,
  "is_answered": false,
  "created_at": "2026-10-28T23:34:13+05:00"
}
```

`author` is `"Anonymous"` when it was left empty. `votes` is the number of upvotes; `voted` says whether
the *calling* voter is one of them.

## Service

### GET /api/

```json
{
  "name": "Raise Hand API",
  "version": "1.0",
  "docs": "http://localhost:8000/docs/",
  "openapi": "http://localhost:8000/openapi.yaml",
  "resources": {
    "lectures": "http://localhost:8000/api/lectures/",
    "questions": "http://localhost:8000/api/questions/"
  }
}
```

### GET /health/

Executes `SELECT version()` on PostgreSQL.

`200` → `{"status": "ok", "database": "PostgreSQL 17.6"}`
`503` → `{"status": "error", "database": "connection refused ..."}`

## Lectures

### GET /api/lectures/ — list

| Query | Meaning |
|---|---|
| `q` | case-insensitive search in the title |
| `is_open` | `true` / `false` — only open or only closed lectures |

```http
GET /api/lectures/?q=introduction
```
```json
{
  "count": 1,
  "lectures": [
    { "id": 1, "title": "Flutter 1 · Lecture 00 · Course introduction", "code": "KBTU26",
      "is_open": true, "question_count": 3, "created_at": "2026-10-28T23:34:13+05:00",
      "join_url": "http://localhost:8000/l/KBTU26/", "screen_url": "http://localhost:8000/l/KBTU26/screen/" }
  ]
}
```

### POST /api/lectures/ — create

| Field | Type | Required | Notes |
|---|---|---|---|
| `title` | string ≤ 120 | yes | |
| `is_open` | boolean | no | default `true` |

```http
POST /api/lectures/
Content-Type: application/json

{"title": "Flutter 1 · Lecture 09 · State management"}
```
`201 Created` → the Lecture object (with the freshly generated `code`).
`400` → `{"error": "'title' is required."}`

### GET /api/lectures/{key}/ — get by id or code

```http
GET /api/lectures/1/        (same as)   GET /api/lectures/KBTU26/
```
`200` → the Lecture object plus `"questions": [...]` ordered like the projector screen:
most upvoted first, answered ones at the bottom. The response sets the `voter` cookie.
`404` → `{"error": "No lecture with id or code '999'."}`

### PUT /api/lectures/{key}/ — replace

Full update: `title` is required; `is_open` defaults to `true` when omitted.

```http
PUT /api/lectures/1/
Content-Type: application/json

{"title": "Flutter 1 · Lecture 00 · Course introduction (updated)", "is_open": true}
```
`200` → the updated Lecture. `400` on validation errors, `404` unknown lecture.

### PATCH /api/lectures/{key}/ — partial update

Send only what changes (at least one of `title`, `is_open`).

```http
PATCH /api/lectures/1/
Content-Type: application/json

{"is_open": false}
```
`200` → the updated Lecture. `400` → `{"error": "Provide at least one of: title, is_open."}`

### DELETE /api/lectures/{key}/ — delete

```http
DELETE /api/lectures/1/
```
`204 No Content` (empty body). The lecture's questions and their upvotes are deleted too (`ON DELETE CASCADE`).
A second delete of the same id returns `404`.

### POST /api/lectures/{key}/toggle/ — open / close

No body. `200` → `{"id": 1, "code": "KBTU26", "is_open": false}`.
A closed lecture answers `409` to new questions.

## Questions

### GET /api/lectures/{key}/questions/ — questions of one lecture

`200` → `{"count": 3, "questions": [Question, ...]}` in screen order (votes desc, answered last).

### POST /api/lectures/{key}/questions/ — ask (create)

| Field | Type | Required | Notes |
|---|---|---|---|
| `text` | string ≤ 500 | yes | |
| `author` | string ≤ 40 | no | empty = Anonymous |
| `voter` | string ≤ 36 | no | explicit voter id (otherwise the cookie) |

```http
POST /api/lectures/KBTU26/questions/
Content-Type: application/json

{"text": "Is EXPOSE enough to publish a port?", "author": "Yevgeniy"}
```
`201 Created` → the Question object.
`409` → `{"error": "This lecture is closed for new questions."}`

### GET /api/questions/ — list all

| Query | Meaning |
|---|---|
| `lecture` | only this lecture (id or code) |
| `answered` | `true` / `false` |
| `q` | case-insensitive search in the text |
| `limit` | page size 1–500 (without it, everything is returned) |
| `offset` | how many to skip (default 0) |

Newest first.

```http
GET /api/questions/?lecture=KBTU26&limit=2
```
```json
{
  "count": 3,
  "limit": 2,
  "offset": 0,
  "questions": [
    { "id": 3, "lecture_id": 1, "lecture_code": "KBTU26",
      "text": "Which IDE should I use: VS Code or Android Studio?", "author": "Daniyar",
      "votes": 0, "voted": false, "is_answered": false, "created_at": "2026-10-28T23:34:13+05:00" },
    { "id": 2, "lecture_id": 1, "lecture_code": "KBTU26",
      "text": "Can I build iOS apps with Flutter on Windows?", "author": "Anonymous",
      "votes": 1, "voted": false, "is_answered": false, "created_at": "2026-10-28T23:34:13+05:00" }
  ]
}
```
`count` is the total number of matches regardless of `limit`/`offset`.

### GET /api/questions/{id}/ — get by id

`200` → the Question object. `404` → `{"error": "No Question matches the given query."}`

### PUT /api/questions/{id}/ — replace

Full update: `text` required; `author` defaults to empty (Anonymous), `is_answered` to `false`.

```http
PUT /api/questions/1/
Content-Type: application/json

{"text": "Do I need to know Dart before Flutter?", "author": "Aigerim", "is_answered": true}
```

### PATCH /api/questions/{id}/ — partial update

At least one of `text`, `author`, `is_answered`.

```http
PATCH /api/questions/1/
Content-Type: application/json

{"is_answered": true}
```

### DELETE /api/questions/{id}/ — delete

`204 No Content`; the question's upvotes go with it.

### POST /api/questions/{id}/upvote/ — toggle upvote

Optional body `{"voter": "any-string"}`; without it the `voter` cookie is used (and created on first call).
First call adds the vote, the second call from the same voter removes it.

`200` → `{"id": 1, "votes": 3, "voted": true}`

### POST /api/questions/{id}/answered/ — toggle answered

No body. `200` → `{"id": 1, "is_answered": true}`

## curl cheat-sheet

```bash
B=http://localhost:8000
curl $B/api/lectures/                                                   # list
curl -X POST $B/api/lectures/ -H 'Content-Type: application/json' \
     -d '{"title":"Demo lecture"}'                                      # create  -> note the id
curl $B/api/lectures/1/                                                 # get by id (or /KBTU26/)
curl -X PATCH $B/api/lectures/1/ -H 'Content-Type: application/json' \
     -d '{"is_open":false}'                                             # update
curl -X POST $B/api/lectures/1/questions/ -H 'Content-Type: application/json' \
     -d '{"text":"Why Compose?","author":"Me"}'                         # create question
curl $B/api/questions/?limit=5                                          # list questions
curl -X DELETE $B/api/questions/1/ -i                                   # delete -> 204
curl -X DELETE $B/api/lectures/1/ -i                                    # delete -> 204
```
